# Household tasks

**What's here:** using Tuit through Family Assistant to capture tasks and track progress.

When Tuit is connected, ask the assistant to capture something to do, show what needs attention,
find a task, record progress, hand it to someone, or mark it complete. For example: “Add a task to
book the plumber” or “What household tasks are waiting on me?”

The assistant acts for you as `family-assistant`. Household tasks are shared; tasks marked private
in Tuit are available through their owner's connection. Handing a task to someone else does not
switch which person's account the assistant uses.

Progress and completion are separate: “I found two plumbers; ask me which one to book” should record
progress and hand the decision back, rather than mark the task done.

If the assistant says your connection is missing or unavailable, the deployment operator needs to
configure or replace your Tuit credential. This integration does not send automatic task
notifications.
